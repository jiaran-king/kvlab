# M1 最小故障定位与 M2：用户授权的新阶段

授权：用户在评审后明确“我同意；请你执行”。不重新开启上一阶段四次预算，也不覆盖旧结果。

范围：一次最多30分钟离线失败链路审查；必要时最多两次定向小复现；条件允许后最多一次完整24GiB M2。原正式协议、负载、并发、timeout、输入输出长度及P/D配置保持不变。有限启动排障最多30分钟、同故障有依据修正一次，禁止盲重启。若小复现同类ready超时复现，停止完整回放计划并保留证据；若抽取成本过大或无法保留竞争条件，可记录依据后直接把一次完整回放作为复现性检验。小复现成功不证明偶发或排除bug。

优先使用已有日志，不为token级一致新增框架。没有记录的链路环节标未知。任何性能相关实现或协议修改需重新判断L/H2可比性。M1永久保留，M2单列。遵守全部SLURM、健康与清理约束。不授权无界故障研究。
